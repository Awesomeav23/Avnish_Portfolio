How it works

  • A conventional project management platform built on React and Next.js, Node and Fastify services, and PostgreSQL. Nothing is generated from a prompt.
  • The AI tab answers questions across project records and uploaded documents. I designed the schema and SQL behind that retrieval.
  • Underneath it, a multi-agent orchestrator runs over six MCP tool servers. The deterministic steps stay deterministic — plain code, same result every run — and only the steps that genuinely need judgement are handed to an agent.

    Pitchwise

    Music practice platform · Sep 2026

    Most practice apps tell you whether a take was good. Pitchwise tells you which note went flat, by how much, and when, while you are still singing it.

    See it running

    Pitchwise is deployed and open to try. The tuner below is the detection surface: microphone or test tone, deviation needle, and a C1–C7 ladder.

    Open Pitchwise ↗

    How it works

    • Pitch detection runs on an AudioWorklet thread, so feedback lands while the note is still sounding.
    • Deviation is reported per note in cents, then collapsed into a scorecard at the end of the take.
    • Lessons are engraved as sheet music with VexFlow. Twelve curricula, 98 lessons, 103 automated checks.

    Better Call Nova

    Amazon Nova AI Hackathon · team of four · Mar 2026

    Uploaded documents go in; structured, stored risk assessments come out: five fields a downstream system can actually act on.

    Watch a document become fields

    Recorded examples with invented documents. The real service calls Amazon Bedrock and writes the result to PostgreSQL.

    Pick a document to send through the service.

    No assessment yet.

    How it works

    • A document posts to one of four REST APIs and comes back as five structured risk fields.
    • Extraction runs on Amazon Bedrock with Nova 2 Lite under a schema-constrained prompt.
    • Every evaluation persists across three PostgreSQL tables modeled with SQLAlchemy, giving the audit trail a chat interface cannot.
